CSS Overflow Properties

Visible (default)

This is a very long text that will overflow the container because overflow is set to visible. The content will spill outside the box boundaries.

Hidden

This is a very long text that will be clipped because overflow is set to hidden. The content that exceeds the container will not be visible.

Scroll

This is a very long text that will show scrollbars because overflow is set to scroll. You can scroll to see the hidden content.

Auto

This is a very long text that will show scrollbars only when needed because overflow is set to auto. Scrollbars appear only if content overflows.

Overflow-X and Overflow-Y

This is a very long text that demonstrates separate horizontal and vertical overflow control. Horizontal scrolling is enabled while vertical is hidden.
